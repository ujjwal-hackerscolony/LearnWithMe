📚 LearnWithMe

«A simple and modern study platform for students from Class 9th to 12th.»

LearnWithMe is an educational website designed to provide students with easy access to Notes, Previous Year Questions, Study Material, and learning resources in one place.

🚀 Features

- 📖 Class 9th to 12th study resources
- 📝 Subject-wise notes
- 📚 Previous Year Questions (PYQs)
- 📑 Study material
- 🌐 Clean and responsive website
- 🌙 Modern dark-blue themed UI
- 📱 Mobile-friendly design
- 🔗 Easy navigation between classes and subjects

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Interactive functionality (if/when added)

🎯 Goal

The goal of LearnWithMe is to create a simple, accessible, and student-friendly learning platform where students can find useful study resources without unnecessary complexity.
